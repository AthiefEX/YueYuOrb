发布日期：2026-10-29

本次整合 v1.1.1 发布后的全部更新：水晶球外观、贴边收缩、翻译与文字提取改进，以及播放设备和音量控制。

- [安装程序](https://github.com/AthiefEX/YueYuOrb/releases/download/v1.2.0/YueYuOrb-1.2.0-win-x64-setup.exe)：当前用户安装，支持覆盖升级。

## 新增功能

- **水晶球显示模式**：保留普通模式，新增包裹图片的立体玻璃外观。球壳随悬浮球尺寸同比缩放，适配图片、时钟及轮盘交互，不添加球体周围特效。
- **左右贴边收缩**：在“设置 → 悬浮球”开启“贴边自动收缩”。鼠标离开 0.8 秒后收缩为窄竖条，移入恢复；拖动、右键菜单、轮盘或音频面板打开时保持完整显示。默认关闭，顶部和底部不收缩。
- **独立提取文字**：轮盘“提取文字”、托盘入口和默认 Ctrl+Alt+E 均可框选提取文字，无需翻译 API 密钥。结果支持选中复制和一键复制；点击顶部“翻译”使用已配置的服务和目标语言直接翻译全文，无需重新框选。等待与失败时保留原文，失败可重试。
- **播放设备与音量**：轮盘“播放设备”打开跟随深浅色主题的面板，可切换默认输出、调整当前设备音量和静音。
- **循环音频组**：在“设置 → 音频”创建多个组，自定义设备顺序和轮盘显示。点击组入口切换到下一个可用设备，跳过断开的设备，保留每台设备原有音量。

## 修复与优化

- 改善小范围、小字号文字首次 OCR 为空时的识别：本机放大并加边距后重试一次。
- 修复从轮盘启动选中文字翻译时，来源窗口焦点恢复与身份判断失败的问题；修复快速切换应用后热键可能使用旧来源窗口的问题。
- 翻译结果框去除产品标题和冗余装饰，支持顶部拖动，译文到达后保留手动调整的位置。
- 修复提取完成后立即点击翻译时结果框被误关的问题；关闭或切换操作后拒绝迟到译文。
- 音频入口统一采用现有轮盘的圆形渐变图标、文字胶囊、阴影和间距，支持轮盘滚动与展开动画。
- 音频面板在设备列表加载或尺寸变化后重新避让屏幕边缘，截图期间自动隐藏；刷新设备期间明确禁用控件，避免操作丢失。

## 升级与说明

- 支持 Windows 10 22H2 x64、Windows 11 x64，发行包自带 .NET 10 运行环境。
- 先从托盘退出旧程序，再启动或覆盖新版。便携版需保留整个文件夹；设置继续使用原有用户数据目录。
- 旧配置如未显示“提取文字”，可在轮盘设置中勾选；播放设备入口及各循环组在音频设置中管理。
- OCR 仍受字号、清晰度及已安装 Windows OCR 语言包影响。
- 音频切换作用于系统默认播放设备；指定独立输出的应用可能不跟随。Windows 三类默认音频角色的切换不是原子操作，遇到设备或驱动错误可能部分完成；失败会提示。
- Windows 默认设备写入使用未公开的 PolicyConfig 接口，未来系统版本的兼容性需持续验证。安装包未做代码签名。
- 自动测试与只读真实设备枚举已验证；实际音频切换、蓝牙断连、Windows 11 和混合 DPI 场景仍需手动验证。
