# 轻量弹幕实施与验证

日期：2026-10-31。范围：用户批准轻量版；真实来源完整桥接仍在后续阶段。

## 已实现

Windows通知读取、旧通知身份基线、严格来源名称筛选、通知标题过滤、关键词高亮；有界消息缓存和过期；横向/纵向显示、减少动画、字体/颜色/字号/透明度/显示时长；显示器、相对位置、区域宽高和拖动缩放预览；设置页、轮盘可选开关、三项可配置快捷键。

Ruling: 采用同程序的可选MSIX通知增强包，而非另建签名助手和跨进程传输 — 现有程序无包身份，直接声明能力可减少消息传输与部署组件 — 代价是便携版只能预览，真实接收需要安装通知版并授权，用户可能需要重新确认原有设置。

Ruling: 持续字幕翻译整个会话暂停弹幕 — 字幕采样不经过普通截图协调器，无法依赖普通隐藏租约 — 代价是字幕翻译期间看不到消息弹幕；停止后仅接收新通知。

Ruling: 轮盘弹幕入口默认不勾选 — 保持现有菜单布局，用户可在消息弹幕设置中加入 — 代价是首次使用需主动开启入口。

## 独立审查与修正

独立审查发现四项重要问题，已处理：

1. 持续字幕可能识别弹幕：字幕状态同步暂停弹幕，停止后建立新基线。
2. 通知权限撤销后积压继续显示：来源显式报告HasAccess=false，运行时清空队列和屏幕；回归 `RevokedAccessDropsPendingMessagesAndSubtitleSessionSuppressesDelivery`。
3. 紧急暂停未接入：现有暂停开关与弹幕自身暂停取逻辑或，不互相取消；运行时暂停测试覆盖不采样。
4. 通知包开机启动未适配：声明StartupTask，异步申请/禁用；设置应用和导入/重置等待注册结果；回归 `AsyncStartupRegistrationIsAwaitedBeforeApplyingPreferences`。
