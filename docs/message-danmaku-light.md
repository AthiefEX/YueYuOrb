# 轻量通知弹幕

2026-10-31 用户明确选择“先实施轻量版”，覆盖原计划阶段A未通过时的范围停止条件。完整三平台接入和第三方桥接仍是后续阶段。

## 当前范围

- 使用 Windows UserNotificationListener，只接收系统实际产生的新通知，来源显示名严格匹配QQ/腾讯QQ、TIM/腾讯TIM、微信/WeChat/Weixin。不同客户端版本可能使用其他显示名，未经验证不自动泛化匹配。
- 开启/恢复后第一批通知仅建立身份基线，不重放旧通知；基线建立前的新通知也可能跳过。每700ms检查新通知，不承诺客户端实时延迟。
- 按通知标题包含文本筛选，每行一个条件；这不是稳定群ID，不区分同名群或群聊/私聊。关键词高亮且加粗，无法可靠识别真正@事件。
- 横向飘过/纵向滚动、颜色/字体/字号/透明度/速度、显示器/区域大小和相对位置、编辑区域预览、轮盘可选开关；可设置总开关、暂停/继续、清空弹幕快捷键，默认不注册。
- 图片、私聊立即插队、精准群选择暂不提供，不能由通知占位内容还原。
- 普通待显示队列100条，30秒过期，缓存仅内存；关闭/暂停/锁屏/截图会清空，结束后不补发旧通知。截图和框选OCR通过现有协调器计数租约隐藏；持续字幕翻译整个会话暂停弹幕，避免聊天正文进入字幕OCR及翻译服务。通知权限被撤销时，下次检查清空积压和屏幕显示。

## 通知授权和便携版

现有便携/安装发布为未打包WPF，通知监听能力需要包身份及用户授权。首版选择对同一程序增加可选MSIX通知增强包，减少新增助手进程和跨进程消息传输。便携版仍可设置和预览，但显示明确提示，不能声称已接收通知。

构建：`powershell -File scripts/build-notification-package.ps1`，输出至 `artifacts/danmaku-light`，不清空其他发布目录。默认生成未签名MSIX；使用与 `CN=YueYuOrb.Local` 主体匹配的代码签名证书时传入 `-CertificateThumbprint`。正式公开发布需受信任的发布签名；本地测试证书的生成/信任和MSIX安装需用户单独授权，不自动导入证书或调整开发者设置。

通知版安装后先退出旧程序，再从开始菜单打开“月语悬浮球（通知增强版）”。设置→消息弹幕→授权通知访问，允许后启用并应用。请用户自行发送一条新消息测试；客户端必须产生Windows通知。授权可在Windows通知访问设置中撤销。

通知包声明独立StartupTask，设置中开机启动使用异步系统接口申请，不保存带版本号的安装目录路径；便携版保持原有启动方式。

运行时不持久化通知标题、正文或图片，不输出日志；Windows自身保存的通知不由月语修改。通知增强包仍可能受独占全屏、系统权限和客户端通知行为影响。

## 验证说明

可自动验证：来源匹配、过滤、高亮、容量/TTL、旧通知不重播、关闭迟到结果、并发捕获/锁屏、设置并发合并及编译打包。

需实际安装授权后验证：QQ/TIM/微信是否发送系统Toast及显示名、真实群私聊标题格式、通知权限撤销、混合DPI拖动、Windows11。未完成这些检查不能宣称三平台消息端到端已通过。
