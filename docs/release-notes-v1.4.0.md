# 月语悬浮球 v1.4.0

本次更新汇总 v1.3.0 发布后的新增功能与修复。消息弹幕功能继续停用，不包含在本次发布中。

## 资源占用显示

- 在「设置 → 常规 → 资源占用显示」中启用 CPU、物理内存或 GPU 占用显示，默认关闭。
- 液体模式：选择一种资源，用球内液面显示占用比例，可自定义颜色。
- 环形模式：可显示一种、两种或三种资源，指示条自动分段，以圆角端点和小间隙区分。
- 环形粗细可在球体直径的 2%–8% 之间调节，随悬浮球尺寸同步缩放。
- 占用达到 90% 时变红；可开启悬停详情，并设置提示延迟。
- 无可用 GPU 数据时显示不可用；悬浮球隐藏或贴边收缩时暂停采样。

## 颜色与轮盘动画

- 资源显示和时间字体支持可视化颜色面板、透明度调整、预设色及直接输入 #RRGGBB / #AARRGGBB。
- 轮盘按钮与半透明指示条从下向上同步扇形展开。
- 常规设置支持 200–800 毫秒展开时长，调整后应用即可生效。

## 修复与体验改进

- 黑夜模式覆盖输入法候选窗等置顶弹窗，改善弹出瞬间的亮度闪现。
- 修复亮度面板调整降暗程度后未保存的问题，改善设置更新的线程协调。
- 快捷键支持单独按键，包括小键盘加减号，以及组合键；不受系统支持或已被占用的键仍可能无法注册。
- 常规设置新增操作系统通知开关。
- 开机自动启动后不再自动打开设置页，手动启动仍保留原有入口。
- 稳定字幕翻译测试的异步等待逻辑。

## 下载与兼容性

- 便携版：解压后运行 YueYuOrb.exe；请保留同目录依赖文件。
- 安装版：当前用户安装，可覆盖升级，保留现有用户配置。
- Windows 10 22H2 x64 / Windows 11 x64；自包含运行时，无需另装 .NET。
- 使用 GPLv3 开源协议。作者：七月风语。

资源占用数值可能因采样口径与任务管理器不同；CPU 采样当前限于单处理器组的 64 个逻辑处理器。Windows 11、混合 DPI、GPU 热插拔与第三方弹窗的最终显示效果仍需实机验证。
