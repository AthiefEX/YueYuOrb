# v1.3.0 发布核验

日期：2026-10-31。发布基线：GitHub正式版本v1.2.0（3e29582）。

## 范围

保留v1.2.0之后的亮度调节、黑夜模式、设置栏目整合、工具窗口内容区优化、弹出面板关闭与位置记忆。暂停并从当前软件移除全部实验弹幕、通知监听、设置/轮盘/快捷键入口和专用MSIX构建、安装脚本。历史提交留在Git中，不改写已有提交历史。

删除前仓库干净。批量恢复曾被自动审查拒绝；随后逐项审查11个共享文件的差异，验证无未提交修改后，只恢复明确的实验引用；新增实验文件逐路径删除，未覆盖其他工作。

## 配置兼容

旧配置的未知快捷键动作在反序列化前过滤，其他偏好及有效快捷键保留；不再识别的独立JSON字段自然忽略。新增测试先复现JsonException，再验证旧主题、悬浮球尺寸和有效快捷键不丢失。SchemaVersion保持1。

## 发布方式

使用独立目录 `artifacts/releases/1.3.0`，没有运行会清空整个artifacts目录的默认发布脚本，保留其他版本、诊断备份和用户数据。便携ZIP、安装EXE及SHA256SUMS.txt上传GitHub，上传后核对长度和服务器摘要；正式发布前确认远端标签指向经验证的源代码提交。

未修改真实屏幕亮度、音频设备和用户设置；Windows11、混合DPI和实际设备写入的手工覆盖仍遵从更新说明中的限制。本机曾安装的通知测试版未被强制卸载，使用正常v1.3.0前应从托盘退出旧测试版。
