# 月语 AI助手使用说明

## 多密钥、模型与联网搜索（1.4.41）

在“连接与模型”点击“新增密钥”，在弹窗填写连接名称、API地址和密钥，点击“保存并读取模型”。左侧为普通文字选择列表，右侧模型/搜索开关与刷新按钮对齐；模型开关控制对应密钥可用状态。原有单密钥会作为“原有连接”显示，继续使用原加密记录，无需重新输入。

模型列表来自该密钥对应接口的 `GET /models`，列表不表示模型实际可用。选择或手填模型后，点击“检测所选模型”发送最小真实聊天请求；服务可能收费。接口不支持模型列表时可手填后检测。检测只证明该模型能返回聊天文字，不证明工具、语音或联网能力。

选择模型后使用下方“用于聊天”和“用于联网搜索”开关，立即生效。右侧显示每个模型最近检测的连接状态，以及是否被选为聊天/搜索。聊天和搜索可以使用同一密钥下的不同模型；只允许一个搜索模型，重复启用会弹出提醒，须先关闭原选择。软件发起的web_search统一路由至此唯一选择，不自动轮换密钥或回退到聊天模型；无法限制第三方服务内部未公开的网络行为。

联网搜索要求聊天模型支持并开启工具调用，搜索模型本身需要服务端具备真实联网检索能力。助手通过 `web_search` 按需调用，只向搜索模型发送本次问题而非整个聊天或记忆；每次确认实际接收方和问题后再发送。支持读取服务的 citations、url_citation 和正文 HTTPS 链接，工具回执中列出来源，可点击来源按钮在默认浏览器打开。来源由模型服务返回，未由软件独立验证；不返回来源时会明确提示，普通聊天模型不能仅靠设置变成联网模型。

在“窗口与入口”设置“助手窗口置顶”，并自定义窗口标题、助手显示名称、用户显示名称。名称只改变窗口和消息显示，不改历史消息的协议角色、权限或任务。

## 开始使用

1. 打开“设置 → AI助手 → 连接与模型”，新增连接并填写兼容 Chat Completions 的 API 地址。
2. 在密码框保存 API 密钥并发现模型，选择模型后“用于聊天”。密钥使用 Windows 当前用户 DPAPI 加密，按连接ID、接口和用途隔离，不写入普通设置或聊天。
3. 点击“检测所选”，确认实际返回文字，再开启助手并点击底部“应用”。工具能力需由服务支持，手动开启“接口支持工具调用”。
4. 在轮盘点击 AI助手，或在“窗口与入口”配置快捷键。默认不占用快捷键，默认不开启助手。

接口地址例：`https://provider.example/v1`；明确回环本地模型可以使用 `http://127.0.0.1:端口/v1`。HTTPS 内网接口需显式勾选允许内网。自动重定向关闭；助手连接不沿用系统代理，DNS 实际连接地址按授权检查，TLS 保留平台验证。

API服务、模型和语音识别的费用由对应供应商决定；软件不自动下载模型，不自动降级到其他云端。

## 对话、素材与记忆

- 支持流式文字、停止、复制、新建/删除对话；默认`Ctrl+Enter`发送，可在“窗口与入口”改为Enter或自定义单键/组合键，仅输入框内生效。Shift+Enter保留换行，输入法组合输入时不会发送。失败时保留未完成回复，当前会话输入可再次编辑。
- “角色与Skill”可导入 UTF-8 Markdown、普通 JSON 角色、Character Card V2 JSON，以及 PNG 内 `tEXt/chara` 编码的 V2 卡。仅支持已说明字段；不支持所有第三方扩展、压缩 iTXt、自动 lorebook 行为。
- Skill 从 `SKILL.md` 或所在目录导入，可读同目录包内 Markdown/text 引用，最多8份、合计64000字符。拒绝越界和文件链接；脚本不自动加载或执行。
- 素材默认不启用，需在列表勾选。素材中的“忽略限制”“无需确认”等文字不能授予权限。
- 右键消息“保存为记忆”，或在“记忆与隐私”手动添加。可编辑、停用或删除；保留来源和修订。删除来源对话会删除派生记忆；删除记忆会清理修订并抑制同一来源再次提取。
- 云端发送启用记忆或私密观察结果时，会展示本次真实消息/工具负载供确认。更改接口、模型或内容后原审批失效。密钥、密码等不应粘贴进聊天或记忆。

## 密钥、模型、项目知识与长期记忆

“连接与模型”点击“新增密钥”弹出同风格窗口填写名称、API地址、密钥和可选初始模型。左栏紧凑列出名称、密钥/模型/搜索开关和刷新按钮；编辑与删除作用于选中的连接。右栏显示可用模型，支持手填ID、选作聊天/搜索，以及所选模型检测、全部检测和停止。全部检测先提示数量与计费，串行逐个请求，显示各模型实际回复或失败状态，不更改当前聊天/搜索模型。关闭密钥或模型不会暗中切换连接；发现列表不等于实际可用或具备联网能力。

## 旧聊天的本地检索

在“AI助手 → 记忆与隐私”开启“按需检索历史聊天”后，新对话可按关键词找回数月前已保存的聊天，无需云端全量阅读。首次打开新版在本地回填索引，之后随消息保存增量更新；工具和系统消息不索引。项目记录仅在该项目召回，全局会话可跨项目召回；删除项目后的旧会话保留用于查看，但不再作为全局检索资料。

历史最多选择4个相关短片段，每段最多1400字符，总历史预算最多4500字符；与长期记忆/知识一起受默认8条、总引用10000字符和整体上下文预算约束，最终发送时还会扣除序列化开销。云端外发历史片段仍须确认；检索本身不调用云端，也不把整份聊天记录外发。时间显示在引用来源中，关键词未命中不能保证找回所有同义表达，日期描述不等于自动精确时间筛选。

删除对话同步清理历史索引，关闭检索开关即可停止旧聊天召回；关闭“保存聊天记录”只停止保存新消息，不会自动删除或禁止检索此前保存的记录。历史索引随用户数据备份恢复，密码与API凭据仍不导出。

“知识库”可建立项目，导入TXT、Markdown、常见代码、DOCX、PDF文字文件；单文件20MiB、提取文字200万字符、PDF最多400页。扫描PDF应先OCR。查看预览后导入，文档只作为参考，不执行宏、脚本或其中指令。新对话可选择项目，产生消息后需新建对话才能改项目；项目资料只供该项目使用，全局资料可跨项目使用。回复引用按钮显示来源、位置和修订。

全文检索不依赖模型。可选本地语义检索需先配置回环地址的兼容embedding服务，再选择该连接并重建索引；模型变化需重新建立对应索引。接口不可用时显示全文检索降级提示，不自动调用云服务。软件只保证请求发往配置的本地第一跳，不能保证用户部署的本地服务器不会自行转发。

知识文档默认禁止云端。选“逐次确认”或“允许相关片段”后，仍受助手实际外发负载审批约束。手动记忆可设项目、类型、分类键、有效期、重要度和云端策略，可查看来源与修订。可选候选提取默认关闭，仅调用明确配置的本地聊天模型：新用户消息持久排队，重启恢复，失败最多自动尝试三次，可手动重置失败任务。模型产生的候选必须逐条审核；冲突替换必须明确确认，不自动覆盖已保存事实。置信度是模型提供的建议值，不是真实正确率。

删除文档、记忆或来源会清除相应索引和派生资料，已被拒绝或删除的候选会抑制再次提取。已生成的聊天回复、原始磁盘文件、此前导出的备份不会因此消失，需分别删除。备份包含项目、知识、引用和队列；恢复时关闭自动提取和向量功能，敏感凭据仍不导出。

本版已用真实本地文档、SQLite全文索引、WPF窗口和本机协议服务验证；未使用用户云端密钥或实际本地大模型验证提取与语义质量。合成标识检索测试不能代表自然语言召回率。

## 电脑操作和自动任务

聊天左栏可展开/收起，顶部新对话，各会话右侧删除图标；左下齿轮打开助手设置，透明度图标展开滑条。语音、停止朗读、停止和发送使用带悬停说明的图标。输入框上方“+”选择主桌面或分身，也可保持自动对象；“@”只为本次消息附加选中Skill，不会改变持久开关。角色/Skill列表右侧可启停、预览、编辑、移除，并支持手动添加。开启角色时自动切换掉此前角色，Skill可同时启用多个；导入后仍需主动开启。

在“操作与任务”分别开启电脑操作、任务管理、角色/Skill编辑权限。允许素材编辑后，支持工具调用的模型可先用assets_list分页读取，再用asset_save提交创建或修改；软件展示完整正文供确认，并以旧hash校验，拒绝覆盖已更新/删除的素材。不执行素材脚本，新素材不自动启用，已有素材编辑后保留原启停状态。

先在设置开启所需的“电脑操作”或“任务管理”。手动选择对象时严格绑定主桌面、本地分身或虚拟机；保持自动对象时，模型须先列出环境，再在每次操作中明确提供environmentId，并由用户审核目标与内容。未确定目标、目标不存在或未就绪时拒绝执行，不回退到主桌面。自动选择不代表无审核地控制任意桌面。

可用能力由现有执行器决定：应用启动/正常关闭、窗口/UI观察、点击、文字输入、按键和亮度等。首次同类操作需确认，临时授权绑定当前会话和目标，最长15分钟，可随时撤销；切换会话/目标、锁屏或关闭助手使授权失效。屏幕/桌面动作可能改变当前用户界面，请先选择正确目标。

应用启动逐次显示完整路径和参数确认。已知命令/脚本解释器和脚本文件禁止走普通应用直接启动入口，需通过完整任务预览审核；不要因窗口写着“应用启动”就省略检查参数。

持久任务必须逐次预览确认，展示步骤、触发器和脚本正文。支持手动、环境就绪、定时触发。脚本只通过已有任务审核与执行器运行，不执行模型直接返回的自由 Shell。虚拟机安装/卸载、系统环境操作仍受来宾 Agent、管理员能力与后端就绪约束。

示例对话：

> 为当前选择的分身保存一个环境就绪任务：等待30秒，然后启动 `D:\Tools\Example.exe`。先展示完整任务让我审核。

任务保存后在“自动任务”页管理。启用手动触发任务可能立即执行；定时任务需要月语运行、目标就绪。已批准任务是确定性的本地规则：关闭助手、断开API后仍可执行，停用需在自动任务页单独操作。助手停用不等于撤回已启用任务。

## 语音

在“语音”配置独立的 `audio/transcriptions` 兼容接口、模型和密钥，并开启语音。点击对话窗“语音”后确认接收方才开始录音，再次点击停止并识别，默认最长30秒（配置上限120秒）。录音只在内存，识别结果默认先进入输入框；自动发送需明确开启。

系统可用时使用 Windows SAPI 朗读，点击“停止朗读”打断；录音时停止朗读以避免自收音。关闭窗口、切换会话/目标、锁屏和停用功能会停止音频并拒绝迟到识别结果。设备、权限或接口失败仍可文字聊天。

协议已用合成音频验证；真实麦克风、声学效果、供应商ASR及系统声音需在自己的设备测试，不承诺所有模型服务都提供语音。

## 外观、数据和限制

助手窗口可拖动边缘缩放，记住位置/尺寸，调整真实整窗透明度。可单独裁切背景图片并调背景透明度，不改动浏览器或其他窗口背景。高对比度模式优先系统可读性。

普通用户备份包含助手数据库（聊天、素材、记忆）和独立背景，排除密钥、录音和网页登录状态；备份本身并未加密，请自行妥善保管。导入后助手、控制权限、已选素材和语音自动发送关闭。删除普通用户数据清除助手数据库与背景，保留本机凭据和虚拟机数据。导入/删除在下次启动执行。

当前已验证本地HTTP/SSE、真实WPF窗口、SQLite、DPAPI、备份隔离和无AI持久任务。真实云端、真实麦克风/朗读、Windows 11、混合DPI和分身内助手操作未完成全面实机验证；不能把协议测试或打包成功视为这些环境已经通过。

测试包不会自动替换现有网络加速后台服务。若新程序提示后台授权版本不匹配，需在“网络加速”使用现有“安装/修复服务”；本次开发未更改网络加速算法、证书或主机网络状态。
