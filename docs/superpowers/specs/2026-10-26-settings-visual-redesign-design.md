# FloatDesk 设置界面视觉重构设计

日期：2026-10-26  
状态：等待设计确认  
技术栈：WPF / .NET 10 / Windows 10 和 Windows 11 x64

## 目标

将现有设置窗口重构为参考图中的冰蓝玻璃工具窗口：自绘紧凑标题栏、横向八段导航、白色分组卡片、统一 Fluent 控件和固定底部操作栏。保留全部已有设置能力、数据绑定、命令处理和本地保存行为。

## 非目标

- 不迁移 WinUI 3、Tauri 或 Electron。
- 不修改快捷应用、输入法锁定、AI 网页、截图、笔记和悬浮球的核心业务行为。
- 不复制参考图中的山湖照片；背景使用 WPF 代码绘制的冷蓝渐变与低对比山形剪影。
- 不新增深色主题作为本次专项，但设置窗口必须继续响应已有系统/浅色/深色主题，并在高对比度模式下退回系统可读样式。

## 设计取舍

### 方案 A：品牌化玻璃窗口（已选择）

使用 `WindowChrome` 自绘圆角外壳和标题栏，保留最小化、最大化、关闭、拖动与缩放。视觉最接近参考图，品牌特征最完整。实现和验证成本较高。

### 方案 B：系统标题栏与品牌内容区

保留原生标题栏，仅重做客户区。系统集成风险低，但无法达到参考图的顶部完整玻璃效果，因此未采用。

## 窗口结构

- 默认 `1160 x 820` DIP，最小 `960 x 620` DIP，可缩放，居中显示。
- 外层 16 DIP 圆角，冷蓝透明感渐变，浅色高光轮廓；不使用 `AllowsTransparency`，避免关闭硬件加速。
- 52 DIP 自定义标题栏显示产品图标、`FloatDesk 设置` 和系统语义的最小化、最大化、关闭按钮。
- 160 DIP 左右的首屏氛围区包含：大标题、用途副标题、`本地保存 · 普通权限` 信任胶囊，以及八段横向导航。
- 导航为：常规、悬浮球、快捷应用、轮盘、输入法、AI 网页、截图、关于。窄窗口允许横向滚动，选中项使用浅蓝底、蓝色前景和轻微投影。
- 中央内容区是唯一主要滚动区域，使用 20 DIP 外边距和卡片间距；宽屏最大内容宽度约 1080 DIP。
- 底部操作栏固定显示保存状态、取消和应用。状态变化仍写入已有 `SaveStatusText`。

## 视觉系统

- 主色 `#2276E8`，深色文字 `#17233B`，次级文字 `#64718A`，冰蓝背景范围 `#DDEBFA` 到 `#F6FAFF`。
- 卡片为 92% 白色，16 DIP 圆角，无重阴影；使用留白和轻微色差建立层级。
- 分组标题采用 18/24、SemiBold；正文 14/20；说明文字 12/18。字体使用 `Segoe UI Variable`，Windows 10 回退 `Segoe UI` 和 `Microsoft YaHei UI`。
- 图标统一使用 `Segoe MDL2 Assets`，保证 Windows 10 可用。
- 卡片内的图标底板为 42 DIP 浅蓝圆角方形；行高与控件至少 40 DIP，主要点击目标至少 40 DIP。
- 简单布尔项改为自定义 Fluent 开关，保留 `CheckBox` 语义和键盘行为。轮盘内置功能的复选项继续使用清晰的多选复选样式。
- 输入框、下拉框、按钮、滑块、表格和滚动条使用窗口级样式，不改动其他窗口的全局外观。

## 页面内容重构

1. 常规：启动与外观卡片、快捷键卡片、导入/导出/恢复偏好操作。
2. 悬浮球：外观、时间显示、位置行为、窗口层级四组设置。
3. 快捷应用：添加工具栏、可调整列宽的表格、加入/移出轮盘与排序操作。
4. 轮盘：内置功能多选卡片，说明所有应用与功能共用一个轮盘及滚轮滚动规则。
5. 输入法：自动锁定总开关、目标键盘布局、规则表格和规则操作。
6. AI 网页：窗口行为、缩放、站点表格和站点操作。
7. 截图：截图选项、输出目录、标注样式。
8. 关于：版本、数据隐私、兼容性边界和权限说明。

所有现有控件名称、事件处理和绑定路径保持兼容，尤其是 `LauncherGrid`、`InputRuleGrid`、`BrowserSitesGrid`、`WheelSettingsTab` 和 `SaveStatusText`。

## 交互与可访问性

- `Tab`、`Shift+Tab`、方向键、空格、回车继续遵循 WPF 原生控件语义。
- 自定义标题栏按钮提供自动化名称和明显焦点框。
- 页面切换使用 120ms 淡入和 6 DIP 上移动画；系统关闭客户端动画时立即切换。不加入循环动画或滚动特效。
- 高对比度模式跳过自绘半透明背景，使用系统颜色和清晰边框。
- 状态文字保留可见文本；错误继续显示在底部操作栏，且不会清空用户输入。
- 窗口缩放时导航横向滚动，表格保持可拉伸；底部操作栏不随内容滚动。

## 实现边界

- 新增 `Resources/SettingsWindowResources.xaml`，承载窗口级颜色、控件模板和卡片样式。
- 重构 `Views/SettingsWindow.xaml`，保留视图模型绑定和全部命名控件。
- 在 `SettingsWindow.xaml.cs` 中增加窗口拖动、标题栏按钮和内容切换处理；不改变设置保存逻辑。
- 必要时增加 Win32 命中测试，使 Windows 11 最大化按钮支持 Snap Layouts 悬停；Windows 10 下回退为标准按钮行为。
- 不新增第三方 UI 依赖。

## 验证

- 先添加结构测试，验证八个导航项、关键命名控件、资源样式和设置绑定仍存在。
- 运行 Release 构建，要求 0 warnings / 0 errors。
- 运行完整测试套件，保持已有测试全部通过。
- 启动 Release 程序，在 100% 和 125% DPI 截取设置窗口，检查内容截断、焦点、导航、卡片层级、表格和底部操作栏。
- 验证拖动、最小化、最大化/还原、关闭隐藏、页面切换和键盘导航。
- 发布自包含 Windows x64 ZIP 到用户输出目录，生成 SHA256 校验文件并执行发布冒烟测试。

## 自检结论

该方案可用现有 WPF 架构完成，风险集中在自绘窗口的系统行为和全页控件模板覆盖。实现顺序会先建立视觉资源与结构测试，再重写页面，最后通过运行时截图和 Release 测试收敛布局。
