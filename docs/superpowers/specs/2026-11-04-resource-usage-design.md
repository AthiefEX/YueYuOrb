# 悬浮球资源占用显示

已批准：常规设置中液体与环形模式独立开关，默认关闭，允许组合。CPU 为全系统占用，内存为物理内存已用比例；GPU 为所选显卡最繁忙引擎占用，默认自动选择最忙显卡。采样每秒一次，后台执行，不安装额外驱动或应用。缺失数据显示不可用而非零。

液体显示一种指标，半透明可选颜色，填充面积与百分比一致，轻微波动、平滑升降，时间在其上。环形指标可选1–3种，一种整圈，两种两等分，三种三等分，间隔细缝，圆头进度、半透明底轨，每项可选颜色。每项>=90%独立变红。

悬停详情可关闭，延迟0.2–5秒，默认0.8秒，展示CPU、物理内存已用/总量和GPU占用；拖动、轮盘打开时隐藏。经典/水晶球、32–128 DIP、图片裁切、贴边收缩、点击和轮盘兼容。外圈在原窗口留白中绘制，并计入贴边边界。关闭/隐藏/退出释放采样与动画。

选择原生Windows采样和WPF绘制，而非外部监控应用或驱动；后者增加安装和兼容负担。Windows10/11 x64，SchemaVersion保持1，不发布或提交此前累积改动。
