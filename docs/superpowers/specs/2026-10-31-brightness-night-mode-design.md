# 全屏幕亮度与黑夜模式设计

日期：2026-10-31。状态：方案已选定，设计待用户批准。

## 目标与选择

用户要求所有屏幕一起调节真实亮度；轮盘提供亮度调节和黑夜模式入口，按钮与 AI 网页、截图一致；设置支持指定亮度、增减亮度快捷键及自定义黑夜降暗程度。

采用方案一：内置屏幕通过 Windows WMI 亮度接口，外接屏幕通过 DDC/CI 调节硬件亮度；每屏独立透明黑色遮罩提供额外视觉降暗。软件降暗不改变硬件值，不宣称降低背光。备选 Gamma 调节可能影响颜色并与 HDR、游戏冲突，不采用。仅硬件调节不能满足最低亮度以下降暗要求。

## 交互与默认值（以下细节为实施方建议）

- 轮盘新增“亮度调节”“黑夜模式”，各自可在设置中隐藏。沿用现有 42 DIP 圆形图标、文字胶囊、尺寸、字体和动画；开启状态除颜色外还提供勾选标识和可访问名称。
- 亮度面板沿用音频面板主题资源、圆角、边框和深浅主题。展示“所有屏幕”、0–100% 总滑条、各屏读数和不可用原因、黑夜开关及降暗滑条。
- 初次打开若各屏亮度不同显示“亮度不同”，滑条以主屏可读值（否则首个可控屏）定位，程序填值不触发写入。用户拖动总滑条后所有可控屏设置相同百分比；百分比不代表相同物理亮度。
- 增减快捷键分别按每屏当前读数加减步长，保留屏间差值，限制 0–100%；无法读取的屏幕跳过并反馈。指定值快捷键统一设置所有可控屏。
- 设置新增“亮度”页：轮盘开关、目标亮度（默认 50%）、增减步长（默认 5 个百分点）、黑夜降暗程度（默认 40%，允许 0–90%）。硬件 0% 映射设备最小值，可能仍有亮光。
- 快捷键动作：打开面板、设定亮度、提高亮度、降低亮度、切换黑夜、紧急关闭黑夜。默认不占用组合键；紧急关闭建议 Ctrl+Alt+Shift+F12，注册失败明确提示并允许改键。轮盘、面板和托盘均可关闭黑夜，不能依赖单一快捷键。
- 降暗程度预览只在黑夜开启时即时生效。持久化程度及配置，不保存开启状态；启动默认关闭。正常退出和进程终止时遮罩随窗口销毁。
- 紧急恢复动作先立即关闭遮罩，再独立请求所有可控屏恢复至 50%，不等待硬件调用才移除遮罩。该动作在快捷键和托盘均可触发，界面明确标注“恢复可见亮度”。硬件最低亮度也会影响软件自身窗口，不能承诺保持原来的物理亮度。
- 悬浮球、轮盘、亮度面板和相关设置窗口在遮罩上方，保持可操作；不自动提高其他应用窗口。保持原有悬浮球全屏隐藏策略。

## 实现结构与并发

- Core 增加亮度设备/快照/逐屏结果、IBrightnessService、BrightnessSettings。AppSettings 新增有默认值的字段，SchemaVersion 保持 1。HotkeyAction 只在尾部添加，旧配置及用户快捷键不覆盖。
- Windows 层枚举并关联显示路径、物理显示器和 WMI 实例；同一设备去重并优先选择适合的单一后端。不能可靠关联的设备不进行猜测写入；报告不可控。镜像模式按唯一物理设备处理，遮罩按桌面显示区域去重。
- 所有 WMI/DDC 查询、写入均在后台执行，释放物理显示器句柄和资源。UI 不等待原生调用；每设备串行，滑条约 100–150ms 合并，仅保留最新待写值。设备间隔离，不让一个失败阻止其他设备。
- 原生同步调用不假定可取消：逻辑超时后丢弃迟到结果，不再向该繁忙设备堆积工作或不断创建线程；其他设备和软件关闭降暗仍可使用。拓扑更新用代次标记拒绝旧设备回调。
- 写入结果逐屏反馈，尝试读回硬件实际值；不把请求值冒充成功读数。设备范围归一化并量化到支持等级。多屏操作非原子，部分成功不回滚已成功设备。
- NightModeController 管理每屏无边框、无任务栏、不激活、鼠标穿透遮罩，使用物理像素边界覆盖含任务栏的完整屏幕。正确处理负坐标、混合 DPI、插拔、休眠恢复和会话切换。锁屏隐藏，解锁按当前运行时意图恢复。
- 统一维护遮罩与本软件控制窗口层级，不用高频争抢前台。黑夜可用于硬件亮度不支持的屏幕。独占全屏、安全桌面及其他顶层覆盖不保证覆盖，HDR 下视觉降暗不保证线性。

## 截图、OCR 与现有功能

- 与现有窗口协调器整合。优先验证系统捕获排除能够得到无遮挡桌面，失败时在捕获期间暂停遮罩，等待显示合成后再捕获。
- 捕获排除 API 返回成功不足以证明有效，必须针对实际 GDI 捕获路径验证；未验证默认走暂停。遮罩重建、拓扑变化时验证失效。字幕会话中途启用黑夜或插入显示器，先建立会话暂停租约，再允许未验证遮罩创建/显示，防止一帧污染及闪烁。
- 暂停采用可嵌套租约/计数；最后一个捕获结束且黑夜仍启用才恢复。异常、取消释放租约，迟到回调不能重新开启已关闭的黑夜。
- 字幕持续捕获不得反复隐藏/显示遮罩造成闪烁：捕获排除有效时正常运行，否则整个字幕会话暂停黑夜并一次提示，停止字幕后按当前意图恢复。
- 弹出亮度面板时阻止贴边收缩；关闭后恢复原计时。面板显示不混入轮盘打开状态，保留轮盘点击收起行为。

## 验证与交付

- 单测：旧配置兼容、范围验证、快捷键冲突、每屏增减/指定值、混合支持/失败、最新值合并、超时与拓扑代次、资源释放、遮罩租约和关闭优先。
- UI 验证：轮盘一致性、主题、面板不越屏、设置持久化；遮罩不抢焦点、不阻挡点击、软件控制入口保持可用；捕获无降暗、字幕无周期闪烁。
- Release 构建零警告零错误，运行现有完整测试；实际硬件写入需要明确记录所测设备和恢复原亮度。无硬件覆盖时只报告模拟及只读验证，不能宣称全部显示器兼容。
- 保持 Windows 10 22H2 x64、Windows 11 x64。暂不包括色温、自动昼夜计划、环境光策略、Gamma 或厂商专有驱动。只交付本地实现和测试；发布 GitHub 另按用户指令。
