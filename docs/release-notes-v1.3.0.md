## 新增功能

- **所有屏幕亮度调节**：轮盘新增亮度面板，统一调整支持的内置屏幕与外接显示器，并逐屏展示实际读数和不可用原因。设置中可配置目标亮度、增减步长及相应快捷键。
- **黑夜模式**：轮盘一键开关，在硬件最低亮度之外通过软件遮罩继续降低视觉亮度，设置中可自定义降暗程度。控制窗口保持可操作，默认恢复可见亮度快捷键为 Ctrl+Alt+Shift+F12；已有用户配置不自动覆盖。
- **浮动面板位置记忆**：播放设备和亮度面板支持从标题区拖动，分别记住上次位置；下次打开恢复并限制在可见屏幕范围。

## 修复与优化

- 普通翻译结果框、播放设备和亮度面板支持点击页面外部自动关闭；在窗口内打开的右键菜单、滑条操作和拖动不会误触关闭。持续字幕显示不受此行为影响。
- 音频设备异步加载后重新校正面板位置；用户手动拖动后保留新位置。面板位置按顺序保存，正常退出先等待位置保存完成。
- 将“快捷应用”设置合并到“轮盘”；将“输入法”和“截图”设置合并到“常规”，减少导航栏目。
- 修复设置导航选中后胶囊背景或边框显示不完整的问题；统一选中项尺寸，横向滚动时保持所选栏目可见。
- 亮度面板改用与整体一致的调节条、分组卡片和胶囊式黑夜模式按钮，提升暗色主题下的可读性。
- 去除 AI 网页和记事本中的大标题与冗余说明，收紧工具栏和底部状态区，将更多窗口空间留给网页和笔记正文。
- 兼容旧配置中的已停用快捷键动作，忽略无效动作，保留原有外观、应用规则和有效快捷键。

## 升级与兼容说明

- 面向 Windows 10 22H2 x64、Windows 11 x64；发行包包含 .NET 10 运行环境。AI 网页仍需要 WebView2 Runtime。
- 先从托盘退出旧程序，再启动新版或覆盖安装。用户数据继续保存在 `%LOCALAPPDATA%\FloatDesk`。
- 内置屏幕通过 Windows WMI、外接屏幕通过 DDC/CI 调节。外接显示器需要支持并开启 DDC/CI；不支持的设备仍可使用黑夜模式。多屏操作可能部分成功，程序会提示，不保证所有显示器和驱动均可控制。
- 黑夜模式是视觉降暗，不改变硬件背光；HDR、独占全屏、受保护画面及其他顶层覆盖场景不保证效果。为避免画面污染和闪烁，持续字幕翻译期间暂时隐藏降暗遮罩，停止后按原开关状态恢复。
- 自动化回归872项全部通过，Release构建0警告、0错误；深浅主题及工具窗口布局已检查。Windows11、混合DPI跨屏拖动和真实硬件亮度写入仍需对应设备手工验证。
- 普通安装包未作代码签名，Windows SmartScreen 可能提示未知发布者。
