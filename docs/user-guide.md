# 月语悬浮球用户手册

## 启动与退出

双击 `YueYuOrb.exe`。关闭设置、AI、笔记或截图窗口不会退出后台进程；悬浮球和托盘继续工作。托盘菜单选择“退出”会停止热键和后台服务。

同一 Windows 会话再次启动会唤起当前实例的设置页，第二进程随后退出。同一用户从另一个 Windows 会话启动时不会共享设置、笔记或 WebView2 profile。

启用“开机启动”后，Windows 使用 `--startup` 参数启动程序，只显示悬浮球和托盘；开机启动被重复触发时直接退出第二个进程，不打开设置页。启用开机启动的旧配置在运行新版后会自动更新启动命令。

## 悬浮球与快捷面板

- 单击悬浮球打开二级面板。
- 应用每次启动都会把悬浮球放到主屏幕工作区内；运行中仍可拖动到其他显示器，重新启动后回到主屏。
- 按住拖动可移动，拖动时悬浮球会轻微放大并在松手后回弹；开启吸附后靠近工作区边缘会贴边。
- 关闭“快捷面板”后，单击球仍可打开。
- 右键悬浮球可直接打开设置、AI、笔记、框选截图、显示/隐藏球或退出。
- “锁定当前位置”同时禁止拖动和位置自动保存。
- 自定义图片会替换默认渐变圆和“月”字标记；透明图片可选“保留透明轮廓”。

在“设置 > 悬浮球 > 外观与尺寸”选择“显示模式”：

- **经典**：保留原有图片呈现和圆形裁切/透明轮廓设置，旧配置默认使用此模式。
- **水晶球**：图片包裹在薄玻璃球内，使用静态球面明暗、边缘反射和局部高光呈现立体感，不添加球外光晕、粒子或底座。尺寸滑块控制完整球体外径，图片直径约为外径的 93%，所有玻璃细节跟随 32–128 DIP 尺寸等比例缩放。

水晶球始终使用圆形边界；原“图片轮廓”选项暂时禁用但偏好会保留，切回经典即可恢复。整颗水晶球都能点击和拖动，包括透明 PNG 的透明部分；球外区域点击穿透。时间仍是无背景文字，位于玻璃高光上方。点击“应用”即可切换模式、尺寸或图片，无需重启。水晶球模式展开轮盘时隐藏球心外围光圈，菜单功能保留。

快捷面板展示整齐排列的功能按钮，包括 AI、记事本、框选截图、窗口截图和当前屏幕截图。左上角的品牌与输入状态卡片已移除；轮盘不再绘制白色背景，只保留从悬浮球指向各菜单项的轻量白色放射条与锚点轨道。球心光晕使用独立透明弹层绘制，悬浮球靠近面板边缘时圆形光晕仍会完整显示。

面板以折扇形式从下向上展开：每个按钮与对应白色半透明指示条同步沿圆弧移动，文字和图标始终保持正向。可在“设置 > 常规 > 轮盘展开速度”调整完整展开时长（200–800 毫秒，默认 400 毫秒）；时长越短越快，点击“应用”后下一次展开生效。关闭时整个轮盘向球心轻微收回并淡出。Windows 关闭“在 Windows 中显示动画”时，这些效果会切换为即时显示与隐藏。

内置功能与加入轮盘的应用共用同一个可滚动轮盘，不再使用独立的应用轮盘。轮盘项目不设数量上限，鼠标悬停在轮盘上滚动滚轮即可浏览；滚动使用约 135–260 毫秒的缓出动画，连续滚动会从当前帧继续追向最新累计目标，不会先跳回起点。超出可视区域的项目会沿不可见的扇形轮廓自动裁切。底部应用坞只显示未加入轮盘的应用，没有此类应用时自动隐藏。Windows 关闭动画效果时会改为即时滚动。

在“设置 > 轮盘”中可以逐项启用或移除内置功能。关闭某项功能只会把它从轮盘移除，不会影响托盘、快捷键或其他设置入口。

## 资源占用显示

在“设置 > 常规 > 资源占用显示”分别开启液体或环形模式，默认均关闭，也可以同时启用。液体选择内存、CPU 或显卡中的一项，以圆形内部的实际面积表示占用比例，可自定义颜色；环形可选择一至三项，各自平分外圈，每项分别设置颜色，圆头指示条之间留有细小空隙。任一指标达到 90% 后，该项显示为红色。

液体位于图片上方、时钟和水晶高光下方；外圈紧贴球体边缘，随悬浮球尺寸缩放。显卡默认自动显示最忙设备，也可指定设备；数据不可用时保留底轨，详情显示“不可用”。CPU 和物理内存为系统占用，显卡按所选设备最忙引擎统计。后台约每秒采样一次，隐藏悬浮球或关闭两个模式后停止采样。

开启“悬停显示详细占用”后，鼠标移到悬浮球或外圈并等待设定的 0.2–5 秒，即可查看 CPU、内存已用/总量以及显卡名称与占用。拖动或打开轮盘时不显示资源提示。颜色可填写 #RRGGBB 或 #AARRGGBB，点击“应用”保存设置。

当前 CPU 采样在超过 64 个逻辑处理器的多处理器组设备上仅覆盖采样线程所在组；普通单组设备为整机占用。显卡驱动不提供性能计数器时显示不可用。贴边收缩为竖条时暂停资源采样和波动动画，恢复球体后继续。

环形指示条粗细可用滑块调整为球体直径的 2%–8%，默认 4.3%，球体缩放时自动按比例变化。液体和各项环形颜色均提供可视化选色：点击颜色块打开面板，拖动色彩区域或调整色相、饱和度、明度及不透明度，也可使用预设色或直接输入颜色代码。在“设置 > 悬浮球”的“显示时间”下可用相同面板设置时间字体颜色，默认白色；点击“应用”后生效。

## 设置快捷应用

在“设置 > 轮盘 > 快捷应用”添加 exe、`.lnk` 或文件夹，快捷应用总数不设上限。选中项目后可编辑名称、每行一个参数和工作目录；上移/下移决定轮盘与底栏的显示顺序。

也可以将一个或多个 `.exe`、`.lnk` 文件直接拖入此页面，自动识别名称、路径和类型。重复文件会跳过，读取失败或不支持的文件会显示提示，其他有效文件仍会添加；点击“应用”保存。读取过程中取消、应用或关闭设置会丢弃尚未完成的拖放结果。快捷方式仍按原 `.lnk` 启动，保留其自身参数和工作目录。

设置列表、轮盘和底部快捷应用栏会自动读取真实应用图标，支持快捷方式的自定义图标。图标在后台加载并缓存在 `%LOCALAPPDATA%\FloatDesk\launcher-icons`；损坏缓存会重新提取，无法读取时显示默认占位图标。图标不会写入设置导出文件。

“加入轮盘”和“移出轮盘”按钮决定应用显示在统一轮盘还是底部应用坞。表格中的“轮盘”列显示当前归属；移出轮盘不会删除应用。点击设置页底部的“应用”后生效。目标被移动或删除时，面板会显示可修复的启动错误。

在“设置 > 轮盘”关闭“显示轮盘下方快捷应用栏”并应用，可隐藏底栏。此开关默认开启，只控制底栏是否显示，不删除快捷应用，也不会改变加入轮盘的项目；重新开启后立即恢复。

## 英文输入规则

“设置 > 输入法”支持：

- 从快捷面板手动开启或停止全局英文锁定。
- 添加指定 exe 的规则，动作选择“锁定英文”或“排除”。
- 排除优先于自动规则和手动锁定。
- 托盘和暂停快捷键可临时暂停后续请求。

目标 KLID 默认是 `00000409`（英语美国）。布局必须是系统中已安装或可加载的英文非 IME 键盘；中文、其他语言和 IME 目标会被拒绝。月语悬浮球解析目标 HKL 后向当前前台线程请求切换，只有读回完全相同的 HKL 时才显示“已验证”。

锁定生效后，月语悬浮球会拦截 `Alt+Shift`、`Ctrl+Shift`、`Win+Space`、`Ctrl+Space` 及 Windows 已配置的布局切换快捷键。未知的第三方切换组合会先快速纠正布局，并在本次运行中学习该组合，后续再按相同组合时直接拦截。锁定只作用于外部前台应用；月语悬浮球自身窗口、排除规则、截图暂停、紧急暂停和锁屏保持豁免。

停止锁定或离开规则应用后，月语悬浮球会请求恢复锁定前保存的 Windows 键盘布局。如果目标窗口已经关闭，会保留待恢复状态并在下一个合适的外部前台窗口执行一次。它不会修改 Windows 的“每个窗口使用不同输入法”偏好，也不保证第三方 IME 私有中英模式；这是一层无需管理员权限的增强用户态锁定，不是操作系统安全边界。

月语悬浮球自身的设置、AI、笔记和标注窗口会被豁免，中文输入不会被全局规则拦截。

## AI 网页

首次打开 AI 网页时创建 WebView2。默认站点为 DeepSeek，可添加最多 10 个 HTTPS 站点。工具条支持后退、前进、刷新、缩放、固定和用默认浏览器打开。

“设置 > AI 网页 > 网页外观”提供“跟随 月语悬浮球”“浅色”“深色”三种模式，默认跟随月语悬浮球。支持 `prefers-color-scheme` 的网站会使用站点的原生明暗样式；DeepSeek 还会同时切换其自身的深色页面状态。其他不支持明暗模式的网站会保持原样，月语悬浮球不会用全局反色强制修改任意页面。

AI 登录弹窗与主 AI 网页使用相同的外观设置。切换月语悬浮球主题、Windows 系统主题或网页外观选项后，已打开的 AI 网页会同步更新；外部默认浏览器不受此设置影响。

登录状态保存在 `%LOCALAPPDATA%\FloatDesk\WebView2`。普通关闭默认挂起网页；开启“关闭窗口即释放网页”会销毁当前 WebView2，未发送内容会丢失。浏览器进程崩溃后点击“重试”会重建 WebView2 控件，profile 保留。

网页权限默认拒绝。顶层 `javascript:`、`file:`、`data:` 和 `about:` 导航被阻止；HTTPS OAuth 新窗口使用独立登录窗口。网页不能调用月语悬浮球本机命令。

## 记事本

- 新建、编辑、搜索标题和正文。
- 停止输入 500 ms 后自动保存。
- 切换笔记、隐藏窗口或退出前会尝试保存。
- 保存失败时正文留在编辑器，列表恢复到原笔记；可重试或导出 TXT。
- 删除先移到回收站，回收站可恢复。
- 最多保存 1000 条活动笔记；正文上限 1 MiB。

## 截图

托盘、快捷面板和右键菜单均提供截图：

- “框选截图”：拖动任意方向选择，Enter 或双击确认，方向键微调，Esc/右键取消。
- “窗口”：捕获最后一次外部前台窗口的可见区域。
- “屏幕”：捕获触发时鼠标所在显示器。

倒计时可点击取消。截图期间月语悬浮球窗口、悬浮球和输入法任务暂停，完成后只恢复截图前原本可见的窗口。

编辑器支持矩形、箭头和中文文字；可设置颜色、线宽与字号。`Ctrl+Z` 撤销、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。确认后默认复制到剪贴板；开启自动保存时另写 PNG/JPEG，`Ctrl+S` 可手动另存。

若剪贴板被占用，会按 50/150/300 ms 重试。复制成功但文件保存失败时，界面会分别说明两种结果。

## 时间与全屏

悬浮球时间支持 12/24 小时制和显示秒。非秒模式会在下一分钟对齐刷新。

全屏策略：

- “跟随普通置顶”：根据“始终位于普通窗口上方”决定层级。
- “自动隐藏”：检测到疑似全屏时隐藏，退出全屏后仅恢复原本可见的球。
- “尽力保持置顶”：尝试保持普通置顶；独占全屏和部分游戏仍可能覆盖。

## 播放设备与音量

轮盘“播放设备”打开设备列表，当前输出前显示勾选标记；点击设备切换 Windows 默认播放设备。面板下方可调整当前设备主音量或静音。明确指定输出设备的应用可能不会随系统默认设备切换。

“设置 > 音频”可配置多个循环音频组，按顺序加入设备并选择是否显示在轮盘。点击组入口切换到下一个已连接设备，跳过不可用设备；当前设备不在组内时选择第一个可用设备。切换保留各设备原来的音量。组内没有其他可用设备时会提示。

## 桌面分身

“设置 > 桌面分身”用于管理实验性本机子会话、Hyper-V 环境、自启动应用和自动任务。此功能默认关闭；启动月语不会探测 Hyper-V、创建 Windows 子会话、启动虚拟机或回退到主桌面执行输入。

诊断区只检查随包文件、功能开关和当前运行时状态，不会主动启用系统能力。当前发布包包含：

- `desktop-sessions/agent/YueYuOrb.SessionAgent.exe`：在受信目标交互会话中执行任务，窗口与输入隔离验证未通过时不得复用主桌面输入。
- `desktop-sessions/broker/YueYuOrb.SessionBroker.exe`：显式安装后以窄权限服务验证父子会话、固定助手哈希和目标用户身份，不接受任意程序路径。
- `desktop-sessions/client/YueYuOrb.SessionClient.exe`：通过本机受认证 IPC 列出环境与任务、提交运行或取消。
- `docs/manual-desktop-sessions.md`：本机子会话、Hyper-V、自启动与任务的人工验收步骤。

本机子会话的生产宿主与窄权限 broker 已接线。诊断页的“安装/修复服务”和“卸载服务”会请求管理员授权；只有服务、随包哈希、真实 WTS/RDP 和输入隔离均验证通过后，本机路线才能解除“实验性”。Hyper-V 仍有协议、来宾助手和生命周期代码，但生产执行宿主与来宾身份探测尚未接入，因此诊断页保持“不可用”。任意路线不可用时只影响该路线，不会把命令发送到主桌面。

## 设置与恢复

“设置 > 悬浮球”的“贴边自动收缩”默认关闭。开启后，悬浮球贴住左右工作区边缘且鼠标离开 0.8 秒，会收缩为窄竖条；鼠标移入恢复完整悬浮球。顶部、底部不收缩。拖动、右键菜单或轮盘展开期间保持完整显示，竖条高度随悬浮球大小变化。

“应用”只合并本次实际修改的字段，因此悬浮球位置或 AI 窗口在设置页打开期间发生的变化不会被旧快照覆盖。取消不会写入。非法快捷键和无效自动保存目录会阻止应用。

“设置 > 常规 > 系统通知”中的“显示操作系统通知”控制本软件的 Windows 系统通知。默认开启；关闭并应用后，亮度调节、播放设备切换、快捷键提示等不再弹出系统通知。重新开启可恢复，选择会保留到下次启动。

快捷键支持单键和组合键，可填写 `A`、`7`、`F8`、`Up`、`Enter`、`NumPad1` 等键名，也可使用 `Ctrl+Alt+Up`。小键盘加减键可填写 `+` / `-`、`Add` / `Subtract` 或 `小键盘+` / `小键盘-`；主键盘加减键使用 `Plus` / `Minus`，两者分别识别。输入后点击“应用”。单键会全局占用，输入文字时也会触发；系统保留键、被其他程序占用的键和部分硬件 Fn 键无法保证注册成功，注册失败时会提示。

导入设置是完整偏好替换，但保留窗口位置，且不会执行快捷项。恢复默认偏好不删除笔记、截图或 WebView2 登录 profile。

主设置损坏时加载 `settings.json.bak`；两份都损坏时重建默认偏好。更高版本 schema 的配置只读，当前版本不会覆盖。

## 翻译与提取文字

- **翻译选中**：在来源应用选中文字，使用 `Ctrl+Alt+T`，或打开悬浮球轮盘选择“翻译选中”。轮盘保留打开时的来源窗口，读取前恢复并验证来源控件焦点；操作进行中手动切走时停止读取，不会反复抢回焦点。
- **框选翻译**：使用 `Ctrl+Alt+O` 或轮盘“框选翻译”，拖出区域后按 Enter 或双击确认。OCR 在本机完成，只有识别后的文字发送给所选翻译服务。
- **提取文字**：使用 `Ctrl+Alt+E`、轮盘“提取文字”或托盘“框选提取文字”。框选后只显示 OCR 文字，不调用翻译服务，无需翻译 API 密钥。旧配置未显示该轮盘项时，在“设置 > 轮盘”勾选“提取文字”并应用；托盘与快捷键可直接使用。

普通结果框只显示处理状态或可选择的结果文字。拖动顶部空白区域或拖动图标可移动位置；点击文字可以选择、使用 `Ctrl+C` 或右键复制选中的部分，顶部复制按钮复制全部结果。新结果返回时保留同一次操作中手动拖动的位置。关闭结果会清空临时文字。

提取文字后，点击结果框顶部的“翻译”，即可使用设置中的翻译服务和目标语言翻译已提取的全文，无需重新框选。等待时保留原文；成功后在同一框中显示可复制的译文，失败时保留原文并允许重试。

各快捷键可在“设置 > 常规”修改。小范围文字首次识别为空时，会在本机进行一次放大并加边距的识别重试；仍无法保证识别极小、模糊、艺术字体或受保护内容。Windows OCR 需要安装对应语言包。

视频字幕继续使用无背景、点击穿透的纯文字层，位置由字幕区域和上方/下方设置决定。普通结果框的拖动和文字选择不改变视频字幕行为。

网络优先选择 Default Switch，并将所选虚拟机连接到该交换机。Windows 的联网图标与真实网络访问可能不一致；需分别检查来宾 IP、默认网关、DNS 和网页访问。月语不会为联网自动关闭宿主防火墙或代理。

## Steam 定向网络加速

在“设置 → 网络加速”使用，无需安装额外客户端。此功能独立实现，不使用 Watt Toolkit 的代码、规则或节点。

1. 保持“一键加速”中的“Steam 兼容模式（证书 + hosts）”开启。默认选择此模式，但不会在启动月语时自动加速。
2. 在“站点与解析”选择商店、社区/创意工坊页面、图片资源。独立解析并行查询 DNSPod / 360 / Cloudflare / Google 的 HTTPS DNS 接口，合并各提供方的合格地址后按 IPv4 优先接入，不改系统 DNS；只要 IPv4 有答案就不再查询 AAAA（实测这些域名的 AAAA 恒为注入地址，每个都会白等 6 秒建连超时），IPv4 无答案时才回退 IPv6。兼容模式始终使用独立解析，且不再降级到系统解析，因为此时系统解析必然返回 hosts 里的回环地址。停止后重新开启加速会清除旧解析缓存。解析修复不改变网络出口，不能保证所有线路可达。
3. 在“检测与恢复”先“检测直连”；若已能访问，可继续使用直连。
4. 首次使用请点击“安装证书”，按 Windows 提示完成管理员授权。这会安装月语专用网络后台与计算机级 `YueYu Steam Background CA` 信任证书；状态显示“已安装 · 后台服务就绪”后，日常只需点击“开始加速/停止加速”，不重复安装、删除证书或请求 hosts 授权。升级后后台与客户端版本不匹配时，重新点击安装按钮修复。点击开始会自动保存网络设置。
5. 点击“检测加速”，使用没有显式代理的真实 HTTPS 连接。面板同时显示接入/活动/失败计数及失败阶段。启动成功不代表可访问；HTTP 200 也不代表账号登录、工坊订阅和下载全部通过。
6. 开启“在轮盘显示一键加速”并应用后，可通过轮盘切换。开始后请重新打开 Steam 页面；接入数一直为 0 时，退出并重启 Steam 清除旧 DNS 缓存。其他代理可能抢先接管连接，月语不会自动关闭它们。
7. 停止或退出时移除自己的 hosts 块并保留其他内容，同时删除本次会话的受保护叶密钥；根证书与后台服务保留，以便下次直接启用。软件重新启动只清理运行期遗留，不删除有效根证书。“恢复网络配置”也只恢复运行期修改。需要彻底移除时点击“卸载证书”：先停止本实例加速，再经管理员授权卸载网络后台、机器根证书及其密钥；其他活动租约存在时拒绝卸载。旧版本留下的当前用户根证书也仅在明确卸载时处理，Windows 可能针对旧证书显示一次删除确认。

兼容模式仅监听 `127.0.0.1:443`，端口已占用时拒绝启动并回滚。只给选定域名签发叶证书；原 hosts 中已有相同域名映射时拒绝覆盖。内容只在内存双向转发，不记录 Cookie、密码或正文。机器 CA 私钥由独立网络后台使用受保护且不可导出的机器 CNG 容器保存，不传给用户界面；叶私钥仍在当前用户受保护的临时 CNG 容器中，停止或中断恢复时删除。后台只接受首次安装所授权账户和匹配发布哈希的客户端，不支持任意域名签发、文件写入或命令执行；当前实现一个后台安装对应一个授权账户，不允许其他账户接管活动租约。
上游连接先发送原始域名 SNI，并始终校验原始域名、可信证书链和有效期。实测这条线路上被阻断的握手会在约 0.04 秒内被重置，而在同一地址上改发不带 SNI 的握手，1.4 秒内就能拿到 CN 为该域名的有效证书：因此握手在证书到达前被重置时，会在同一地址上立即并试不带 SNI 的握手，且仍必须通过相同的证书链与原始域名验证；证书被拒、HTTP 错误都不会触发回退。这个升级不依赖开关：开关关闭时，只要确认到证书到达前的握手重置同样会自动改试无 SNI；开关开启时，其它握手失败也会补一次无 SNI 尝试。握手重置属于逐次发生而非逐地址固定的网络抖动，因此标准阶段每个地址在重置后会再试两次；单次尝试 7 秒、TCP 建连 4 秒，整批地址的上游总时限 24 秒（更早的 5 秒/3 秒/20 秒在 SYN 丢失突发时连建连都来不及完成，页面还没开始就报总超时）。TCP 建连超时不重试：同一死地址每次结果都一样，重试只会占用其他候选的时间。整批地址都连不上时会丢弃缓存重新解析，因为被过滤的网络对同一域名会交替返回真实地址与不可路由地址。成功握手过的边缘地址会记住 10 分钟（写入数据目录的 `steam-network-edges.json`，重启后仍生效），并排在候选首位；即使本次解析只返回污染地址也会先试它，它仍必须重新通过完整的证书链与域名校验，连接失败即丢弃。
状态会分别显示本地 TLS 接入、上游 TLS 验证成功和实际双向传输。最近失败按商店、社区两个站点组分别保存：同组成功才会清除本组失败，商店成功不会掩盖社区失败，启动类失败在任一站点成功后清除；也可在设置中手动清除。
根证书有效期 90 天，剩余不足 7 天且没有活动租约时由已授权后台维护；叶证书有效期 2 天，每次开始重新签发。后台持有的 hosts 租约会在客户端断线或退出后自动恢复；后台异常退出后由 Windows 重启服务并恢复自身日志中记录的遗留租约。状态页会提示后台连接断开，避免把断开的租约显示为正常。
关闭兼容模式后可使用旧 PAC 模式：需开启“PAC 模式应用到系统”，已有活动代理时拒绝覆盖，不采用系统 PAC 的客户端不会接入。手动 PAC 地址只在该模式运行时有效，不要配置到其他电脑。
此功能属于本地代理技术，不是 VPN，不改变网络出口。完全不可达的线路、固定证书校验、游戏下载和全部工坊资源不保证可用；未包含的域名继续直连。
