# 月语悬浮球用户手册

## 启动与退出

双击 `YueYuOrb.exe`。关闭设置、AI、笔记或截图窗口不会退出后台进程；悬浮球和托盘继续工作。托盘菜单选择“退出”会停止热键和后台服务。

同一 Windows 会话再次启动会唤起当前实例的设置页，第二进程随后退出。同一用户从另一个 Windows 会话启动时不会共享设置、笔记或 WebView2 profile。

## 悬浮球与快捷面板

- 单击悬浮球打开二级面板。
- 应用每次启动都会把悬浮球放到主屏幕工作区内；运行中仍可拖动到其他显示器，重新启动后回到主屏。
- 按住拖动可移动，拖动时悬浮球会轻微放大并在松手后回弹；开启吸附后靠近工作区边缘会贴边。
- 关闭“快捷面板”后，单击球仍可打开。
- 右键悬浮球可直接打开设置、AI、笔记、框选截图、显示/隐藏球或退出。
- “锁定当前位置”同时禁止拖动和位置自动保存。
- 自定义图片会替换默认渐变圆和“月”字标记；透明图片可选“保留透明轮廓”。

在“设置 > 悬浮球 > 外观与尺寸”选择“显示模式”：

- **经典**：保留原有图片呈现和圆形裁切/透明轮廓设置，旧配置默认使用此模式。
- **水晶球**：图片包裹在薄玻璃球内，使用静态球面明暗、边缘反射和局部高光呈现立体感，不添加球外光晕、粒子或底座。尺寸滑块控制完整球体外径，图片直径约为外径的 93%，所有玻璃细节跟随 32–128 DIP 尺寸等比例缩放。

水晶球始终使用圆形边界；原“图片轮廓”选项暂时禁用但偏好会保留，切回经典即可恢复。整颗水晶球都能点击和拖动，包括透明 PNG 的透明部分；球外区域点击穿透。时间仍是无背景文字，位于玻璃高光上方。点击“应用”即可切换模式、尺寸或图片，无需重启。水晶球模式展开轮盘时隐藏球心外围光圈，菜单功能保留。

快捷面板展示整齐排列的功能按钮，包括 AI、记事本、框选截图、窗口截图和当前屏幕截图。左上角的品牌与输入状态卡片已移除；轮盘不再绘制白色背景，只保留从悬浮球指向各菜单项的轻量白色放射条与锚点轨道。球心光晕使用独立透明弹层绘制，悬浮球靠近面板边缘时圆形光晕仍会完整显示。

面板会从悬浮球方向平滑展开：靠近球心的入口先出现，其余入口依次向外弹出；关闭时整个轮盘向球心轻微收回并淡出，完成后再隐藏窗口。Windows 关闭“在 Windows 中显示动画”时，这些效果会切换为即时显示与隐藏。

内置功能与加入轮盘的应用共用同一个可滚动轮盘，不再使用独立的应用轮盘。轮盘项目不设数量上限，鼠标悬停在轮盘上滚动滚轮即可浏览；滚动使用约 135–260 毫秒的缓出动画，连续滚动会从当前帧继续追向最新累计目标，不会先跳回起点。超出可视区域的项目会沿不可见的扇形轮廓自动裁切。底部应用坞只显示未加入轮盘的应用，没有此类应用时自动隐藏。Windows 关闭动画效果时会改为即时滚动。

在“设置 > 轮盘”中可以逐项启用或移除内置功能。关闭某项功能只会把它从轮盘移除，不会影响托盘、快捷键或其他设置入口。

## 设置快捷应用

在“设置 > 快捷应用”添加 exe、`.lnk` 或文件夹，快捷应用总数不设上限。选中项目后可编辑名称、每行一个参数和工作目录；上移/下移决定轮盘与底栏的显示顺序。

也可以将一个或多个 `.exe`、`.lnk` 文件直接拖入此页面，自动识别名称、路径和类型。重复文件会跳过，读取失败或不支持的文件会显示提示，其他有效文件仍会添加；点击“应用”保存。读取过程中取消、应用或关闭设置会丢弃尚未完成的拖放结果。快捷方式仍按原 `.lnk` 启动，保留其自身参数和工作目录。

设置列表、轮盘和底部快捷应用栏会自动读取真实应用图标，支持快捷方式的自定义图标。图标在后台加载并缓存在 `%LOCALAPPDATA%\FloatDesk\launcher-icons`；损坏缓存会重新提取，无法读取时显示默认占位图标。图标不会写入设置导出文件。

“加入轮盘”和“移出轮盘”按钮决定应用显示在统一轮盘还是底部应用坞。表格中的“轮盘”列显示当前归属；移出轮盘不会删除应用。点击设置页底部的“应用”后生效。目标被移动或删除时，面板会显示可修复的启动错误。

在“设置 > 轮盘”关闭“显示轮盘下方快捷应用栏”并应用，可隐藏底栏。此开关默认开启，只控制底栏是否显示，不删除快捷应用，也不会改变加入轮盘的项目；重新开启后立即恢复。

## 英文输入规则

“设置 > 输入法”支持：

- 从快捷面板手动开启或停止全局英文锁定。
- 添加指定 exe 的规则，动作选择“锁定英文”或“排除”。
- 排除优先于自动规则和手动锁定。
- 托盘和暂停快捷键可临时暂停后续请求。

目标 KLID 默认是 `00000409`（英语美国）。布局必须是系统中已安装或可加载的英文非 IME 键盘；中文、其他语言和 IME 目标会被拒绝。月语悬浮球解析目标 HKL 后向当前前台线程请求切换，只有读回完全相同的 HKL 时才显示“已验证”。

锁定生效后，月语悬浮球会拦截 `Alt+Shift`、`Ctrl+Shift`、`Win+Space`、`Ctrl+Space` 及 Windows 已配置的布局切换快捷键。未知的第三方切换组合会先快速纠正布局，并在本次运行中学习该组合，后续再按相同组合时直接拦截。锁定只作用于外部前台应用；月语悬浮球自身窗口、排除规则、截图暂停、紧急暂停和锁屏保持豁免。

停止锁定或离开规则应用后，月语悬浮球会请求恢复锁定前保存的 Windows 键盘布局。如果目标窗口已经关闭，会保留待恢复状态并在下一个合适的外部前台窗口执行一次。它不会修改 Windows 的“每个窗口使用不同输入法”偏好，也不保证第三方 IME 私有中英模式；这是一层无需管理员权限的增强用户态锁定，不是操作系统安全边界。

月语悬浮球自身的设置、AI、笔记和标注窗口会被豁免，中文输入不会被全局规则拦截。

## AI 网页

首次打开 AI 网页时创建 WebView2。默认站点为 DeepSeek，可添加最多 10 个 HTTPS 站点。工具条支持后退、前进、刷新、缩放、固定和用默认浏览器打开。

“设置 > AI 网页 > 网页外观”提供“跟随 月语悬浮球”“浅色”“深色”三种模式，默认跟随月语悬浮球。支持 `prefers-color-scheme` 的网站会使用站点的原生明暗样式；DeepSeek 还会同时切换其自身的深色页面状态。其他不支持明暗模式的网站会保持原样，月语悬浮球不会用全局反色强制修改任意页面。

AI 登录弹窗与主 AI 网页使用相同的外观设置。切换月语悬浮球主题、Windows 系统主题或网页外观选项后，已打开的 AI 网页会同步更新；外部默认浏览器不受此设置影响。

登录状态保存在 `%LOCALAPPDATA%\FloatDesk\WebView2`。普通关闭默认挂起网页；开启“关闭窗口即释放网页”会销毁当前 WebView2，未发送内容会丢失。浏览器进程崩溃后点击“重试”会重建 WebView2 控件，profile 保留。

网页权限默认拒绝。顶层 `javascript:`、`file:`、`data:` 和 `about:` 导航被阻止；HTTPS OAuth 新窗口使用独立登录窗口。网页不能调用月语悬浮球本机命令。

## 记事本

- 新建、编辑、搜索标题和正文。
- 停止输入 500 ms 后自动保存。
- 切换笔记、隐藏窗口或退出前会尝试保存。
- 保存失败时正文留在编辑器，列表恢复到原笔记；可重试或导出 TXT。
- 删除先移到回收站，回收站可恢复。
- 最多保存 1000 条活动笔记；正文上限 1 MiB。

## 截图

托盘、快捷面板和右键菜单均提供截图：

- “框选截图”：拖动任意方向选择，Enter 或双击确认，方向键微调，Esc/右键取消。
- “窗口”：捕获最后一次外部前台窗口的可见区域。
- “屏幕”：捕获触发时鼠标所在显示器。

倒计时可点击取消。截图期间月语悬浮球窗口、悬浮球和输入法任务暂停，完成后只恢复截图前原本可见的窗口。

编辑器支持矩形、箭头和中文文字；可设置颜色、线宽与字号。`Ctrl+Z` 撤销、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。确认后默认复制到剪贴板；开启自动保存时另写 PNG/JPEG，`Ctrl+S` 可手动另存。

若剪贴板被占用，会按 50/150/300 ms 重试。复制成功但文件保存失败时，界面会分别说明两种结果。

## 时间与全屏

悬浮球时间支持 12/24 小时制和显示秒。非秒模式会在下一分钟对齐刷新。

全屏策略：

- “跟随普通置顶”：根据“始终位于普通窗口上方”决定层级。
- “自动隐藏”：检测到疑似全屏时隐藏，退出全屏后仅恢复原本可见的球。
- “尽力保持置顶”：尝试保持普通置顶；独占全屏和部分游戏仍可能覆盖。

## 设置与恢复

“应用”只合并本次实际修改的字段，因此悬浮球位置或 AI 窗口在设置页打开期间发生的变化不会被旧快照覆盖。取消不会写入。非法快捷键和无效自动保存目录会阻止应用。

导入设置是完整偏好替换，但保留窗口位置，且不会执行快捷项。恢复默认偏好不删除笔记、截图或 WebView2 登录 profile。

主设置损坏时加载 `settings.json.bak`；两份都损坏时重建默认偏好。更高版本 schema 的配置只读，当前版本不会覆盖。

## 翻译与提取文字

- **翻译选中**：在来源应用选中文字，使用 `Ctrl+Alt+T`，或打开悬浮球轮盘选择“翻译选中”。轮盘保留打开时的来源窗口，读取前恢复并验证来源控件焦点；操作进行中手动切走时停止读取，不会反复抢回焦点。
- **框选翻译**：使用 `Ctrl+Alt+O` 或轮盘“框选翻译”，拖出区域后按 Enter 或双击确认。OCR 在本机完成，只有识别后的文字发送给所选翻译服务。
- **提取文字**：使用 `Ctrl+Alt+E`、轮盘“提取文字”或托盘“框选提取文字”。框选后只显示 OCR 文字，不调用翻译服务，无需翻译 API 密钥。旧配置未显示该轮盘项时，在“设置 > 轮盘”勾选“提取文字”并应用；托盘与快捷键可直接使用。

普通结果框只显示处理状态或可选择的结果文字。拖动顶部空白区域或拖动图标可移动位置；点击文字可以选择、使用 `Ctrl+C` 或右键复制选中的部分，顶部复制按钮复制全部结果。新结果返回时保留同一次操作中手动拖动的位置。关闭结果会清空临时文字。

提取文字后，点击结果框顶部的“翻译”，即可使用设置中的翻译服务和目标语言翻译已提取的全文，无需重新框选。等待时保留原文；成功后在同一框中显示可复制的译文，失败时保留原文并允许重试。

各快捷键可在“设置 > 常规”修改。小范围文字首次识别为空时，会在本机进行一次放大并加边距的识别重试；仍无法保证识别极小、模糊、艺术字体或受保护内容。Windows OCR 需要安装对应语言包。

视频字幕继续使用无背景、点击穿透的纯文字层，位置由字幕区域和上方/下方设置决定。普通结果框的拖动和文字选择不改变视频字幕行为。

## 故障处理

- AI 显示“WebView2 尚不可用”：安装/修复 WebView2 Runtime，点击重试，或使用默认浏览器。
- 英文规则显示 Unsupported/Denied：确认英语（美国）布局已安装、目标为普通权限窗口并允许布局切换。
- 快捷键冲突：到“设置 > 常规”换键；托盘菜单始终可用。
- 截图复制失败：稍后重试，或使用“另存为”保存文件。
- 需要诊断：查看 `%LOCALAPPDATA%\FloatDesk\logs`，日志不包含笔记正文或截图内容。
