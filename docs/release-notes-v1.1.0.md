# 月语悬浮球 v1.1.0

发布日期：2026-10-27

本次更新加入完整的实时翻译能力，包含“翻译选中”“框选翻译”和“字幕翻译”
三个入口，并新增适合视频播放的透明字幕浮层。翻译服务、语言设置、快捷键、
轮盘动作和隐私策略可以在设置中统一管理。

## 更新重点

### 三种翻译入口

- **翻译选中**：复制当前应用中选中的文字并显示原文与译文，结束后尽力恢复
  原剪贴板内容，不保留选择内容。
- **框选翻译**：框选屏幕区域后使用 Windows OCR 在本地识别文字，再将识别
  结果发送到翻译服务。
- **字幕翻译**：固定视频字幕区域并持续检测画面变化，识别新字幕后异步翻译，
  将译文显示在字幕区域上方、下方或自动选择的一侧。

三个入口可通过默认快捷键 `Ctrl+Alt+T`、`Ctrl+Alt+O` 和
`Ctrl+Alt+L` 调用，也可以在快捷键设置中修改。轮盘设置新增对应动作开关。

### 实时字幕体验

- 采样、OCR 和翻译采用“最新字幕优先”的分离流水线，网络翻译不会阻塞下一帧
  字幕检测。
- 新译文返回前继续显示上一条有效译文；新译文首次非空时一次性替换旧译文，
  避免新旧文字重叠、空白帧和可感知闪烁。
- 字幕层为点击穿透的透明纯文字窗口，不显示背景卡片、标题、原文和控制栏，
  不会挡住视频播放器或桌面点击。
- 支持字幕上方、字幕下方和自动位置；支持 100–1500 ms 画面检测间隔、
  60%–100% 文字不透明度以及 14–36 DIP 字号。
- 托盘菜单可在字幕会话中暂停、继续、重新选择和停止翻译。
- 自动放置会避开字幕捕获区域，并处理屏幕边缘、负坐标显示器、窗口尺寸变化
  和混合 DPI 布局。

### 翻译服务与设置

- 默认使用无需账号和 API 密钥的 MyMemory 免费服务。
- 支持 Azure Translator、DeepL、LibreTranslate 和 OpenAI 兼容接口。
- 自定义服务可以设置接口地址、API 密钥、模型名称及 Azure 区域。
- API 密钥使用 Windows DPAPI 当前用户范围加密，不写入
  `settings.json`，也不会包含在设置导入或导出文件中。
- 设置页提供目标语言、原文语言、Windows OCR 语言和连接测试；OCR 语言列表
  只显示当前系统已安装的识别语言。
- 新旧设置文件保持兼容，已有悬浮球、轮盘、笔记、截图和键盘布局配置不会被
  覆盖。

## 隐私说明

- 截图、裁切图像和 OCR 位图不会上传，也不会写入临时文件。
- 只有用户选中的文字或屏幕 OCR 识别出的文字会发送给所选翻译服务。
- 不保存翻译历史，不记录选中文字、OCR 原文、译文或 API 密钥。
- 不使用自定义服务失败时自动切换到其他供应商，避免在用户不知情时改变数据
  去向。
- 免费公共翻译服务仍受服务商每日额度、单次长度和可用性限制。

## 兼容性与修复

- 保持 Windows 10 21H2/22H2 x64 与 Windows 11 x64 目标框架兼容。
- 修复字幕浮层在暂停、继续、重新选择、停止和供应商切换时的取消与迟发结果
  处理。
- 修复新字幕定位失败时旧译文被隐藏的问题。
- 修复混合 DPI 或窗口尺寸变化后，安全位置已经恢复但状态仍被判定为失败的
  问题。
- 增强捕获互斥、字幕捕获排除、操作令牌和关闭流程，避免字幕浮层被再次 OCR
  或旧操作改写新会话。

## 已知边界

- Windows 11、双显示器混合 DPI 和真实播放器覆盖场景仍需在对应设备上完成
  人工验收。
- Windows OCR 依赖系统已安装的语言包；手写、艺术字、过小文字和部分语言可能
  无法识别，应用不会自动安装语言包。
- “翻译选中”依赖目标应用接受标准 `Ctrl+C` 复制；受保护内容、提权窗口和不
  提供文本复制的应用无法保证可用。
- 不翻译音频、麦克风、DRM 或受保护视频内容，也不读取播放器内部字幕轨。
- 第一阶段字幕翻译在完整译文返回后显示，逐字流式翻译留待后续版本。
- MyMemory 及其他第三方服务的额度、网络延迟和可用性由服务商决定。

## 升级与许可

从 `v1.0.0` 升级不需要手动迁移设置；翻译相关字段使用兼容默认值，API 密钥
需要在首次使用时重新输入。
