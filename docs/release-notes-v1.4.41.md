# 月语悬浮球 v1.4.41

本次发布汇总 v1.4.0 之后已完成的功能与修复，提供 Windows x64 便携版、安装版和来宾 Agent 配套包。继续使用 GPLv3，作者七月风语。

## AI助手与本地资料

- 新增可独立开关的AI助手，支持兼容API、多把加密密钥、模型发现、单个/全部实际检测和返回结果。
- 密钥采用文字选择列表；模型显示最近检测状态及聊天/搜索用途。聊天和联网搜索可使用同一密钥下的不同模型，只允许一个搜索模型，重复启用会提醒。
- 聊天窗口使用可收起的会话列表、逐项删除、统一图标、透明度滑条；支持Enter、Ctrl+Enter和自定义发送键，并处理输入法组合输入及Alt系统按键。
- 输入框上方“+”选择主桌面/本地分身/虚拟机，也可由模型提出目标，执行前确认；“@”为本次消息调用Skill。
- 角色与Skill支持导入、手动添加/编辑、启停；角色最多启用一个。可选AI素材编辑会展示完整正文并检查旧hash，不执行素材脚本，不自动授予电脑权限。
- 长期记忆、项目知识库、TXT/Markdown/代码/DOCX/PDF文字导入、来源引用、本地全文检索、可选本地向量检索与候选记忆审核。
- 可按需检索数月前已保存聊天：本机索引，仅发送相关短片段；默认关闭，云端外发仍需确认。不会全量上传历史聊天。

## 悬浮浏览器与设置

- AI网页升级为悬浮浏览器：收藏/书签、地址导航、启动页、边缘缩放、真实透明度、默认鼠标穿透与快捷键切换交互。
- 悬浮球、轮盘与快捷应用、悬浮浏览器、实时翻译、音频和亮度集中到“悬浮球与轮盘”子标签。
- 统一玻璃圆角窗口，改善网页、记事本、本地分身和Hyper-V控制台外框。
- 自定义背景支持裁切与图片透明度；普通用户数据支持导出/导入/删除，不包含虚拟机、敏感凭据和网页登录状态。
- 修复黑夜模式下悬浮球自身未被降暗等体验问题。

## 桌面分身与自动任务

- 本地分身与Hyper-V分别配置；增加虚拟机创建、启动、关闭、保存、控制台、资源设置、网络修复、自动登录、共享文件夹及GPU-P配置入口。
- Windows自动安装、来宾Agent导出/部署/配对、模板流程与控制台状态反馈；现有环境仍需满足Windows、Hyper-V、来宾网络和Agent条件。
- 自动任务独立设置，区分本地分身、虚拟机和全局目标；任务启停、脚本导入、定时和环境就绪触发。
- MCP支持受信任外部agent和任务管理；AI助手自己的控制权限、会话确认与任务审核相互独立，目标不可用时不回退主桌面。

## 网络加速

- 增加Steam相关站点加速、诊断与后台服务；证书管理提供安装、卸载和状态显示，避免每次启停重复安装证书。
- 部分模式会使用本地TLS处理与受管hosts规则；退出/关闭时按既定流程还原。网络可用性取决于实际线路、DNS与服务，不能保证所有环境均有效。
- 测试版升级后若提示后台服务授权版本不匹配，请使用“网络加速 → 安装/修复服务”，本次发布不自动更改已安装服务。

## 下载与使用

- 便携版：`YueYuOrb-1.4.41-win-x64-portable.zip`，完整解压后运行`YueYuOrb.exe`。
- 安装版：`YueYuOrb-1.4.41-win-x64-setup.exe`，当前用户安装；保留现有用户数据。
- 来宾配套：`YueYuOrb-1.4.41-session-agent-win-x64.zip`；只在明确配置的分身/来宾环境使用。
- 校验：`SHA256SUMS.txt`。安装包未签名，本次未执行覆盖安装或改动用户虚拟机。

AI助手默认关闭，需自行配置API；云端费用及联网能力由供应商决定。使用说明见[AI助手指南](ai-assistant-guide.md)、[用户手册](user-guide.md)、[桌面自动任务](desktop-automation-guide.md)。

## 验证与边界

- Release构建0警告0错误；1578/1578项自动化测试通过（Core218、Infrastructure212、Windows375、UI773）。
- 已用隔离数据、真实WPF窗口、SQLite和本机HTTP/SSE验证连接、检测、知识/旧聊天检索、会话布局、角色唯一启用和重复搜索提醒。
- 尚未全面验证真实云端供应商、真实语音设备、Windows11与混合DPI、所有显卡/游戏/来宾环境；协议测试不等于这些后端已实测。
- 普通置顶窗口不能保证覆盖真正独占全屏游戏。GPU-P受硬件/驱动/系统限制，保存状态与任务管理器显示也存在平台限制。
- 自动任务和电脑操作依然需要目标就绪与相应授权；导入素材或模型文字不能提升权限。
